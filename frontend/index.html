Disponibilidad de equipos

Cuándo puede trabajar cada equipo: festivos, mantenimiento e interrupciones reducen su capacidad semana a semana. La planeación y la ocupación usan estos valores.

Mapa del año

Cada columna es una semana. Haz clic en una para editarla o agregar una excepción.

Registrar cambios de disponibilidad

Reduce la capacidad de un equipo en una semana concreta. Si esa semana ya tiene una excepción, se reemplaza.

Calendario de disponibilidad

El año completo de un equipo, semana por semana. Cada semana muestra el porcentaje de capacidad disponible; los festivos, el mantenimiento y las bajas de productividad se marcan con color y se listan abajo.

Requerimientos de material

Cuánto material necesita cada equipo para entregar el tonelaje pedido, calculado hacia atrás con el rendimiento de cada equipo. Elige un pedido para ver dónde se pierde el acero, o el mes completo para ver el total. Sin fechas: eso corresponde a la planeación mensual.
